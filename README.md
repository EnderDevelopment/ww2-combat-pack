# WW2 Combat Pack

The WW2 Combat Pack is a Minecraft mod that recreates the WW2 experience with vehicles, weapons, and structures. This modpack includes a variety of WW2-themed items and features to immerse players in a realistic World War II environment. It is designed for Fabric Loader and Minecraft 1.20.1.

## Install

1. Download the WW2 Combat Pack mod file.
2. Place the downloaded file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric Loader installed.

## Use

1. Launch Minecraft with the WW2 Combat Pack mod installed.
2. Explore the new WW2-themed items and structures.
3. Use the provided vehicles and weapons to engage in combat and strategic gameplay.
